ARK ASA Configuration Manager - Términos de Uso para Servidor Comunitario
=========================================================================

AVISO IMPORTANTE: Al instalar este software y operar un servidor dedicado de
ARK: Survival Ascended, usted acepta los siguientes términos:

1. USO NO COMERCIAL
   Este software es gratuito y de código abierto (licencia MIT).
   El servidor que configure debe ser de uso personal o comunitario,
   sin cobro de acceso, cuotas de membresía ni ningún tipo de pago a cambio
   de jugar en él.

2. SERVIDOR COMUNITARIO (NO COMPETITIVO)
   El servidor está destinado exclusivamente para juego informal entre
   amigos o una comunidad abierta. No está permitido su uso en torneos
   con premios en dinero ni en competencias organizadas con fines de lucro.

3. TÉRMINOS DE STUDIO WILDCARD

   compromete a cumplir con los Términos de Servicio de Studio Wildcard /
   Snail Games, incluyendo:
   - No modificar el servidor para obtener ventajas desleales.
   - No distribuir contenido protegido por derechos de autor del juego.
   - No hacer uso abusivo de las APIs ni de los sistemas de Steam.

4. TÉRMINOS DE STEAM / VALVE

   los Subscriber Agreement de Steam. El servidor de ARK: Survival Ascended
   Dedicated se descarga gratuitamente vía Steam App ID 2430930 bajo

   el operador es el único responsable de:
   - El contenido y conducta dentro del servidor.

   - El cumplimiento de las leyes locales aplicables.
   - Los costos de ancho de banda e infraestructura derivados de operar
     el servidor.

6. DATOS DE JUGADORES

   en el mundo, estadísticas), eres responsable de gestionar dichos datos
